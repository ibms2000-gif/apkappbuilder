# APK App Builder

منصة عربية أولية لتحويل وصف المستخدم إلى كود تطبيق Android باستخدام Groq وGemini، ثم بناء Debug APK عبر GitHub Actions وتخزينه في Cloudflare R2.

## الحالة

- واجهة عربية RTL لكتابة البرومبت وعرض المشاريع وحالة البناء والتنزيل.
- Worker API لاستدعاء Groq/Gemini مع fallback.
- D1 لتخزين المشاريع وحصص الاستخدام اليومية.
- قالب Kotlin + Jetpack Compose ثابت.
- GitHub Actions لبناء APK عند الطلب وإرجاعه إلى R2.
- الحصص ومفاتيح AI موجودة على الخادم؛ لا تُرسل إلى المتصفح.

## البدء

راجع دليل الإعداد الكامل: [docs/SETUP_AR.md](docs/SETUP_AR.md).

**تنبيه:** هذا MVP تجريبي وليس منصة إنتاجية مكتملة. لا توجد عضويات أو معاينة مباشرة أو مفاتيح توقيع Release لكل مستخدم. معرّف الحصة الحالي محفوظ في المتصفح ويمكن تغييره، ولا يُعد حماية كافية من إساءة الاستخدام. راجع حدود مزودي الذكاء الاصطناعي وسياسات استخدام البيانات قبل فتح الخدمة للعامة.
