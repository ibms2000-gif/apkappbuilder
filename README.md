# APK App Builder

منصة عربية لتحويل وصف المستخدم إلى تطبيق Android باستخدام Groq وGemini، ثم بناء APK وإنشاء تقرير إنجاز طلابي PDF مع QR code ونشر الملفين علناً في GitHub Releases.

## المزايا الحالية في المستودع

- واجهة عربية RTL لوصف التطبيق وإدخال اسم الطالب / المنشئ.
- Worker API يستدعي Groq مع Gemini كخيار احتياطي.
- D1 لتخزين المشاريع وحصص الاستخدام وروابط الإصدارات.
- قالب Android أصلي Kotlin + Jetpack Compose.
- GitHub Actions لبناء Debug APK لكل مشروع.
- إنشاء PDF عربي من صفحة واحدة باسم التطبيق ووصفه واسم الطالب وتاريخ الإنشاء ورمز QR يفتح رابط تنزيل APK.
- إنشاء GitHub Release مستقل لكل مشروع، وفيه ملف APK وملف PDF، بروابط عامة.
- لا يحتاج المشروع إلى Cloudflare R2.

## ملاحظات مهمة

- المستودع عام؛ جميع ملفات APK والتقارير وروابطها متاحة للجميع عبر GitHub Releases.
- الحصة الافتراضية محاولتان يومياً لكل معرّف متصفح. هذا حاجز تجريبي وليس نظام عضويات أو حماية قوية من التحايل.
- المخرجات الحالية تطبيق Compose أولي بملف `MainActivity.kt` واحد، ولا تنشئ تلقائياً خدمات خلفية أو صلاحيات حساسة أو موارد متعددة.
- الناتج الحالي Debug APK للتجربة وليس إصدار Release موقعاً بمفتاح نشر خاص.
- تقرير PDF عام ويعرض اسم الطالب/المنشئ. استخدم اسماً وافقت المدرسة والطالب على نشره.
- لا ترسل كلمات مرور أو مفاتيح أو معلومات طلاب حساسة في البرومبت.
